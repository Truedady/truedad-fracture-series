# TrueDad · «История заработка в Steam» — монтаж кадров 14–78

Документальный монтаж в Remotion: настоящие страницы Valve и прессы, архивы, плавная камера,
анимированные экраны статистики со звуком. **Рендер — на вашем Windows-компьютере, сразу в 2K (2560×1440).**

Длительность каждой сцены подстроена под её текст в сценарии (`src/narration.json`, ≈ 14,5 знака в секунду),
всего ≈ 20,4 мин, 65 сцен, 151 план (в среднем ~8 с на план). После записи голоса достаточно поменять
секунды в `src/narration.json` — планы и переходы пересчитаются сами.

## Запуск (PowerShell)
```powershell
cd D:\Claud\truedad-fracture-series\history-film
git pull
npm.cmd ci
npm.cmd run doctor
npm.cmd run render:scenes
```
Результат — по файлу на главу: `output\<глава>_1440p.mp4` (2560×1440, 30 fps, звук AAC 320k).

| Команда | Что делает |
|---|---|
| `npm.cmd run doctor` | проверяет Node, FFmpeg, пакеты, все картинки/звуки и их размеры |
| `npm.cmd run preview` | Remotion Studio в браузере — можно листать кадры |
| `npm.cmd run render:scenes` | все главы → `output/<глава>_1440p.mp4` |
| `npm.cmd run render:scenes -- Ch06-Pubg` | одна глава: `Ch02-Tail` (14–15), `Ch03-Regional` (16–22), `Ch04-Markets` (23–28), `Ch05-SteamGuard` (29–32), `Ch06-Pubg` (33–37), `Ch07-WorstSpring` (38–42), `Ch08-InvestBoom` (43–51), `Ch09-Stickers` (52–58), `Ch10-CS2` (59–63), `Ch11-NewEconomy` (64–74), `Final` (75–78) |
| `npm.cmd run render:final -- --approved` | 2560×1440 @ 60 fps, после утверждения монтажа и озвучки |
| `npm.cmd run audit:links` | проверка ссылок из `SOURCES.json` → `link_audit.csv` |

## Структура
```
src/narration.json   секунды и текст каждой сцены (из сценария)
src/chapters.tsx     все сцены: какие планы, движение камеры, веса по фразам
src/film.tsx         раскладка планов по времени, автоматическое чередование переходов
src/engine.tsx       камера по странице (push/pull/scroll/panR/panL/tilt/drift), фото, переходы, звуки
src/graphics.tsx     анимированные экраны статистики со звуками
src/quote.tsx        цитата патчноута с появлением слов
public/sources/      настоящие страницы (Playwright, 2×) и официальные изображения
public/local/        архивы курса (в кадре не подписываются)
public/sfx/          звуки анимаций и переходов (scripts/make-sfx.py)
shot_timeline.json   таблица: сцена → текст → планы с таймингом
```

## Принципы монтажа
- Камера чередуется: наезд, отъезд, прокрутка, панорамы влево/вправо, наклон, дрейф; приближение не больше ×1,45 от 2×-скриншота.
- Переходы чередуются: затемнение между темами, сдвиг, вертикальный сдвиг, «whip», зум, размытие, кроссфейд; на сдвигах и зумах — звук.
- Экраны статистики анимированы (счётчики, графики, ячейки дней, схемы) и озвучены щелчками, «поп», подъёмом тона, ударом.
- В кадре нет подписей источников и служебных пометок; выделение текста — не чаще одного раза за план.
- Условные примеры помечены словами «ПРИМЕР» / «МОДЕЛЬ».
