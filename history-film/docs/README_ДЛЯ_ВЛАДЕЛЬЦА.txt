TrueDad — пакет для Claude Code: КАДРЫ 14–78, локальный Windows-рендер.

1) Распакуй ZIP в папку на компьютере.
2) Открой папку в Claude Code и дай ему команду: «Прочитай CLAUDE_CODE_START_HERE.md. Создай запускаемый проект, опубликуй в приватном GitHub и остановись после черновика кадров 14–18».
3) Claude создаёт рабочий код; размещает его на GitHub при наличии доступа и твоего согласия; даёт реальную ссылку. Здесь ещё НЕТ готового видеопроекта и GitHub-репозитория.
4) После `git clone` на Windows запускаешь `npm ci`, `npm run doctor`, `npm run preview` и `npm run render:draft`.
5) Ты проверяешь первый черновик; пока ты не одобришь — кадры 19–78 не собираются.
6) Для финального 2K 60FPS нужна остальная озвучка; MP3 для вступления сюда не приложена, потому что первые 13 кадров исключены.

Технические детали: CLAUDE_CODE_START_HERE.md, WINDOWS_LOCAL_RENDER.md, FIRST_DRAFT_14-18.md.
