# TrueDad · Fracture — плейбук рубрики (утверждено автором после Day 01, ревизия 5)

Эталон: `renders/fracture-day01.mp4` (коммит c579230). Новые выпуски делаются **в этом же стиле**, меняются только озвучка, футаж, факты и тайминги.

## Производство выпуска
1. Озвучка → пословная расшифровка локально (sherpa-onnx: GigaAM-v2 RNNT + Zipformer-ru для перекрёстной проверки; модели берутся из GitHub Releases k2-fsa/sherpa-onnx — HuggingFace в облачной среде закрыт). Слова — только из аудио, числа цифрами.
2. `captions/dayNN.asr-raw.json` → `scripts/build-captions.py` → `data/dayNN.captions.json` (страницы 2–5 слов, ключевые слова/числа со `*`).
3. Скопировать `src/episodes/day01.ts` → `dayNN.ts`: beats (границы сцен по началу слов), cues, clips, sfx. Сцены и компоненты не переписывать.
4. Футаж: **только авторский исходник в полном качестве** (1080p+), не сжатые прокси. Таймкоды клипов находить сопоставлением кадров, кадрирование — в reference-пространстве 1600×900. Зум не больше ~1,7–2× от исходных пикселей.
5. Рендер `npm run render` (master + finalize: yuv420p BT.709 limited, −1,5 dB, стоп-кадры), затем QC по кадрам каждые 0,5–1 с и замер звука.

## Визуальный стиль (утверждён)
- Графит `#0B0E13`, карточки `#151A22`, золото `#D9A93D` только для бренда/покупок/ключевых чисел, красный `#E54C58` только для падения рынка.
- Шрифты: Manrope (текст, субтитры), Unbounded (крупные числа), IBM Plex Mono (метки, источники). Self-hosted из `public/fonts`.
- Фон: 2.5D перспективная сетка пола, пыль, зерно, виньетка. HUD: TRUEDAD + чип «FRACTURE CASE · ДЕНЬ NN/30» + тонкий прогресс.
- Кадр 0 уже содержит хук (заголовок + реальная красная кривая), никаких заставок.
- Кинетические субтитры по словам в нижней безопасной зоне (y≈1330), активное слово — вспышка, ключевые — золото.
- Каждые 1,5–3 с новый смысловой акцент; пустых пауз в кадре нет (плейсхолдеры «··» до произнесения числа, призрачный план баров).
- Переходы 8–14 кадров: whip / push / rise, без глитчей и вспышек.
- Кейс-герой: качественный рендер `public/assets/source/fracture_case_hq.webp`, вырезка `scripts/cutout-case.py` (мягкая альфа, без белого ореола).

## Факты (жёстко)
- Графики рынка — только оцифровка реальных скриншотов Steam (`scripts/digitize-chart.py`) с подписью источника.
- Реальные доказательства: диалог Buy Order, «Success», плитки в инвентаре с обводкой и счётчиком NN/NN, запись портфеля.
- Сумма покупки — только произнесённая автором и подтверждённая портфелем/квитанцией. Прибыль/P&L трекера в кадр не попадает (кропы сужать).
- План (будущие дни) — контурные бары, купленное — сплошное золото. Последовательность 20 + 5·(n−1), итог 2 775.
- Вкладки браузера, баланс, ник — никогда в кадре; сырой футаж в git не коммитить.

## Звук (утверждён автором)
- Голос — главный: эффекты на **13–25 дБ ниже пиков голоса**, все SFX + бед ≈20 дБ ниже речи по RMS. Итог ≈ −17 LUFS, пик ≤ −1 dBFS.
- **Мало звуков, без повторов.** Никаких тиков на каждое число и вжухов на каждую смену сцены. Бед — тихий пэд без ритмичного пульса.
- **У каждого графика свой звук**, все тональные, в ре миноре (`scripts/generate-sfx.py`):
  - падающая кривая Steam (старт): тональный глиссандо вниз + мягкий саб — **автору нравится, не менять**;
  - рост лесенки: 6 восходящих мallet-нот пентатоники;
  - годовой график: **«мелодия данных»** — 12 щипков, высота = реальная средняя цена месяца, панорама L→R — **утверждено**;
  - бары 20/25/30: три щипка с повышением; каскад до 165: тихое быстрое арпеджио;
  - накопительная кривая: нарастающий пэд + колокольчик точно на итоговом числе;
  - мини-графики «рынок ↓ / закупки ↑»: пары нисходящих/восходящих сигналов.
- **Отклонено автором:** шумовой «даун-свип» вместо глиссандо на старте; «сканирующий» тон с шумом на годовом графике; громкие импакты и частые вжухи.
- Прочие акценты (≤6 на ролик): тик на ключевой цифре, вжух при входе в эксперимент и в покупку, короткий вжух на кейсе, «confirm» на «куплены», тик на финальном CTA.

## Формат ежедневных выпусков (День 2+) — `src/FractureDay2.tsx`, `src/scenes/DailyScenes.tsx`
Запрос автора к Дню 2: **75–80 % хронометража — реальное видео**, меньше рисованной графики, числа поверх настоящего интерфейса.
- Исходники дня лежат в GitHub Release `day-NN-assets`; скачать: `bash scripts/fetch-day.sh NN <файлы>`; проверить ffprobe; не пережимать.
- `FootageStage`: камера по записи (ключевые кадры `shots`), вертикальный кроп на весь экран или «карточка» с размытым фоном того же кадра, затемнение второстепенного + золотая рамка (`spots`), лёгкий дрейф-наезд.
- `CompareCard`: «вчера → сегодня» с бегущим числом и чипом изменения поверх интерфейса — одна карточка на показатель, без отдельных графических сцен.
- Порядок сцен: хук (кейс → лоты ▲) · «день NN» · лоты и мин. цена · диалог ордера · мой ордер (SIH) · Success · инвентарь «Новый предмет 1/NN» + лесенка вчера/сегодня/завтра · прогноз над месячным графиком + «завтра день NN+1».
- Всё дневное — в `src/episodes/dayNN.ts` (`daily.yesterday/today`, клипы, камеры, подсветки, cues, sfx). Координаты — в пространстве 1600×900 (= 4K / 2,4).
- Цена ордера ≠ цена сделки: подписывать «заявка, ещё не сделка»; исполнение подтверждать только инвентарём.
- Звуки: те же утверждённые файлы, тихо, без повторов: спад на хуке, восходящие ноты на росте лотов, mini-up/mini-down на изменениях, confirm на Success, щипки 20/25/30 на лесенке.
