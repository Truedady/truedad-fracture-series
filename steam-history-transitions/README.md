# TrueDad · «История заработка в Steam» — переходы между главами

Remotion-проект с анимированными заставками глав для документального фильма
«ИСТОРИЯ ЗАРАБОТКА В STEAM: ОТ 2011 ДО 2026 ГОДА». Концепция — в [VISUAL_CONCEPT.md](VISUAL_CONCEPT.md).

## Готовые файлы
| Глава | 4K-мастер | Превью 1080p | Длительность |
|---|---|---|---|
| 01 · Первые обмены · 2010–2013 | `renders/4k/01_pervye-obmeny_2010-2013_2160p30.mp4` | `renders/1080p/…_1080p30.mp4` | 4,5 с · 135 кадров |
| 07 · Худшая весна для трейдеров · 2018 | `renders/4k/07_hudshaya-vesna_2018_2160p30.mp4` | `renders/1080p/…_1080p30.mp4` | 5,0 с · 150 кадров |

Стоп-кадры начала / середины / конца — `renders/stills/`.

**Версии со звуком** — `renders/4k_zvuk/` и `renders/1080p_zvuk/` (AAC 320 кбит/с, 48 кГц, стерео,
≈ −16 LUFS, пик −1 dBFS). Отдельные дорожки для монтажа — `renders/audio/*_sfx.wav` (48 кГц / 24 бит):
их можно положить на свою дорожку и сбалансировать с музыкой и голосом.
Звук полностью синтезирован кодом (`scripts/sound/sfx.py`) — сторонних сэмплов и вопросов с правами нет.
Пересобрать звук и сведение: `bash scripts/sound/mux.sh` (нужны Python 3 + numpy + scipy и FFmpeg).

Формат: 16:9, 3840×2160 (мастер) и 1920×1080 (превью), **30 fps** для всех глав,
H.264 High, yuv420p (BT.709). Есть версии без звука и со звуком. Первые ~6 кадров — проявление из чёрного, последние — уход в чёрный,
так что заставку можно ставить встык или с коротким кроссфейдом.

## Запуск и рендер
Нужны Node.js 18+ и FFmpeg (Remotion при первом запуске сам скачает headless Chromium).
```bash
npm install
npm run dev                      # Remotion Studio: просмотр и правки в браузере
node scripts/render-all.mjs      # все главы: 4K + 1080p + стоп-кадры в renders/
node scripts/render-all.mjs Ch07-WorstSpring   # одна глава
```

## Структура
```
src/
  Root.tsx                    регистрация композиций (1920×1080 @30, 4K = --scale=2)
  lib/theme.ts                палитра, шрифты, безопасные зоны
  lib/anim.ts                 easing, тряска камеры, дрейф
  lib/fonts.ts                загрузка шрифтов из public/fonts (корректная кириллица)
  components/Atmosphere.tsx   фон, виньетка, зерно, пыль
  components/Typography.tsx   «ГЛАВА 0X», годы, хронологическая шкала
  components/Icons.tsx        векторные предметы: шляпа, ключ, металл, ящик, оружие, кейс, замок
  chapters/Ch01FirstTrades.tsx
  chapters/Ch07WorstSpring.tsx
```
Все тайминги в каждой главе записаны в номерах кадров в шапке файла — чтобы ускорить или
удлинить заставку, достаточно сдвинуть числа и поменять `CHxx_DURATION`.

## Шрифты и лицензии
Inter / Inter Display и JetBrains Mono — SIL OFL; DejaVu Sans — свободная лицензия Bitstream Vera.
Предметы нарисованы вручную векторно и не являются игровыми ассетами Valve или Krafton.
