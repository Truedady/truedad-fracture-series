# TrueDad · «История заработка в Steam» — переходы между главами

Remotion-проект с анимированными заставками глав для документального фильма
«ИСТОРИЯ ЗАРАБОТКА В STEAM: ОТ 2011 ДО 2026 ГОДА». Концепция — в [VISUAL_CONCEPT.md](VISUAL_CONCEPT.md).

## Готовые файлы
Все 11 переходов, каждый отдельным файлом (`NN_название_годы`):

| Папка | Что внутри |
|---|---|
| `renders/4k_zvuk/` | **4K-мастера со звуком** — 3840×2160, 30 fps, H.264 + AAC 320 кбит/с |
| `renders/4k/` | те же 4K-мастера без звука |
| `renders/1080p_zvuk/`, `renders/1080p/` | превью 1920×1080 со звуком и без |
| `renders/audio/` | отдельные звуковые дорожки WAV 48 кГц / 24 бит |
| `renders/stills/` | стоп-кадры начала / середины / конца каждой главы |

Длительность 4,5–5,5 с. Каждая заставка проявляется из чёрного и уходит в чёрный — ставится встык
или с коротким кроссфейдом. Видео — BT.709, стандартный диапазон.

## Запуск и рендер
Нужны Node.js 18+, FFmpeg и Python 3 с numpy и scipy (для звука). Remotion при первом запуске сам скачает headless Chromium.
```bash
npm install
npm run dev                      # Remotion Studio: просмотр и правки в браузере
node scripts/render-all.mjs      # все главы: звук, 4K, 1080p, стоп-кадры, версии со звуком
node scripts/render-all.mjs Ch07-WorstSpring   # одна глава
```

## Структура
```
src/
  Root.tsx                    регистрация композиций (1920×1080 @30, 4K = --scale=2)
  lib/theme.ts                палитра, шрифты, безопасные зоны
  lib/anim.ts                 easing, тряска камеры, дрейф
  lib/fonts.ts                загрузка шрифтов из public/fonts (корректная кириллица)
  components/Atmosphere.tsx   фон, виньетка, зерно, пыль
  components/Typography.tsx   «ГЛАВА 0X», годы, хронологическая шкала
  components/Icons.tsx        векторные предметы: шляпа, ключ, металл, ящик, оружие, кейс, замок
  components/TitleBlock.tsx   общий блок названия главы (9 вариантов появления, 3 варианта ухода)
  components/Skins.tsx        реестр реальных скинов из public/skins/
  components/Items2.tsx       векторные предметы: кейсы, наклейки, капсула, плащ, подарок
  chapters/Ch01…Ch11*.tsx     одиннадцать глав, тайминги в шапке каждого файла
scripts/
  render-all.mjs              полный рендер
  sound/sfx.py                синтез звука для всех глав
  sheet.sh                    быстрый контактный лист кадров для проверки
```
Все тайминги в каждой главе записаны в номерах кадров в шапке файла — чтобы ускорить или
удлинить заставку, достаточно сдвинуть числа и поменять `CHxx_DURATION`.

## Шрифты и лицензии
Inter / Inter Display и JetBrains Mono — SIL OFL; DejaVu Sans — свободная лицензия Bitstream Vera.
Скины в `public/skins/` — рендеры предметов, присланные автором канала (права на них — у Valve).
Остальные предметы нарисованы векторно вручную. Звук синтезирован кодом, сторонних сэмплов нет.
