# «История заработка в Steam: 2011–2026» — визуальная концепция переходов

## Идея: «Архив эпох»
Зритель не листает слайды, а **летит через слои истории Steam**. Каждая глава — короткая
сцена внутри «интерфейса своей эпохи», после чего камера выходит из него и открывает
название главы. Интерфейсы меняются вместе со временем: оливковый клиент Steam 2010 года →
тёмные инвентари CS:GO → PUBG → чистый современный интерфейс CS2. Через это зритель
ощущает смену эпох без всякой «машины времени» и шаблонных таймлайнов.

## Единая система (повторяется в каждой главе)
| Элемент | Правило |
|---|---|
| Фон | Графит `#0B0E13` → чёрный, мягкое пятно света за титром, виньетка, плёночное зерно 7–8% |
| Акцент | Приглушённое золото `#D9A93D` — только годы, нить сделки, шкала (≈5–10% кадра) |
| Красный / зелёный | Только по смыслу: красный — блокировки, запреты, падение; зелёный — рост/разрешение |
| Титр | Inter Display Bold 146–156 px, белый `#F4F1E9`, по центру title-safe |
| «ГЛАВА 07» | JetBrains Mono, разрядка, две золотые чёрточки |
| Годы | JetBrains Mono, золото, линии расходятся из центра |
| Подпись | Мелкая моно-строка с ключевыми событиями главы (можно отключить) |
| Хронология | Шкала 2010–2026 внизу. Главы — **отрезки**, а не точки, поэтому пересечения периодов (2011–2017 и 2013–2017) показаны честно |
| Безопасная зона | Ключевой текст внутри 10% title-safe (192 × 108 px от краёв в 1080p) |

## Грамматика движения зависит от настроения главы
* **Рост / зарождение** (01, 02, 06, 08, 11): плавный долли, мягкие кривые, предметы «дышат»,
  буквы проступают из расфокуса. Выход — *полёт вперёд*: камера продолжает движение,
  предметы проносятся мимо объектива, затемнение.
* **Ограничения / кризис** (05, 07): быстрая камера → **полная остановка времени**,
  удар, обесцвечивание, красные замки. Титр раскрывается жёсткой «шторкой» из одной
  линии. Выход — шторка схлопывается в линию, линия в точку, резкий чёрный.
* **Масштаб / рынок** (03, 04, 09, 10): работа количеством и ритмом (много предметов,
  карты, смены интерфейсов), но без выдуманных цифр и графиков.

Анимация текста в главах намеренно разная: 01 — буквы поднимаются из размытия
с проходом светового блика; 07 — шторка из линии. Для остальных глав запланированы
свои варианты (маска по форме предмета, «печать» ценником, раскрытие через перегородки
инвентаря и т.д.).

## Пробная 01 · «Первые обмены» · 2010–2013 (4,5 с, 135 кадров)
| Кадры | Что происходит |
|---|---|
| 0–12 | Из темноты, в расфокусе, проступает инвентарь старого Steam (оливковый клиент, шрифт Verdana-типа) |
| 8–48 | Два обмена одновременно: шляпа ⇄ ключ, металл ⇄ ящик. Предметы поднимаются над сеткой, разворачиваются к камере и пролетают по двум встречным золотым дугам — «линзе сделки». По интерфейсу проходит полоса света |
| 38–56 | Камера ныряет в интерфейс: наезд + расфокус, инвентарь растворяется |
| 46–70 | Те же предметы остаются в пространстве как боке вокруг титра; под титром — «пол» из сетки слотов, уходящий к горизонту |
| 53–94 | ГЛАВА 01 → ПЕРВЫЕ ОБМЕНЫ (буквы из размытия + световой блик) → 2010 — 2013 → подпись → шкала |
| 94–110 | Удержание для чтения |
| 110–135 | Полёт вперёд: титр уходит на камеру, предметы и пыль проносятся мимо, затемнение |

| Кадры | Что происходит |

## Подсказки для звука (необязательно)
* 01: мягкий «whoosh» на кадрах 40–56, тёплый пэд/рисер к титру, короткий щелчок/«тик» на кадре 68 (годы).
* 07: нарастающий ритм тиков на 0–42, **резкая тишина + низкий удар на кадре 42**, «клац» замков 44–56,
  короткий высокий тон на появлении линии (80), глухой «drop» на 126–145.

## Факты и честность
* Даты на экране взяты из сценария: 29.03.2018 (7-дневный трейдлок CS:GO), 03.05.2018 (PUBG
  отключает личные обмены). Никаких цен, графиков или статистики в пробных заставках нет.
* Номера в «журнале обменов» и подписи «ТРЕЙД-БОТ 01–04» — декоративные элементы интерфейса,
  не реальные данные.
* Предметы — собственные стилизованные векторные силуэты «по мотивам эпохи», не копии игровых
  ассетов. При наличии прав их можно заменить официальными рендерами (`src/components/Icons.tsx`).
