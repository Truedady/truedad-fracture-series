# TrueDad — «Монтаж без излишеств»: стиль и процесс (файл знаний проекта)

## Эталон
- Репозиторий `Truedady/truedad-fracture-series`, ветка `claude/montazh-bez-izlishestv`.
- Эталонный ролик: день 2 (`src/news/cinema/fractureDay02Footage.tsx`, композиция `FractureDay02-Footage`,
  черновик `renders/fracture-day-02/truedad-fracture-day02-draft-v2.mp4`).
- Шаблон: `src/news/cinema/TrueDadNewsCinema.tsx`, заставка `Opening` в файле дня 2. Звуки: `public/news/sfx/{boom,shimmer,click,key,tick}.wav`
  (собираются скриптом `scripts/make_sfx.py`). Вырезка кейса: `scripts/cutout_case.py`.

## Параметры
- Окно футажа: 1080×1300 при y=190; камера в пикселях исходника, высота кадра = 1,2·ширина.
- Фон: тот же футаж, размытие 46 px, яркость 0,38. Грейд: контраст 1,06, насыщенность 1,08, виньетка.
- Переход: 0,6 с, входящий план из размытия 14 px → 0, масштаб 1,04 → 1.
- Спотлайт: затемнение 0,58 с мягким краем, появление 0,6 с, один за раз.
- Субтитры: Inter 800 / 56 px / y=1540; ≤22 символов; активное слово #D9A93D.
- Звук (громкость): boom 0,35 на 0 с; shimmer 0,16 на блике (0,55 с); tick 0,08 на «ДЕНЬ N»; click 0,25 / key 0,15 на реальные
  клики и нажатия (искать по сменам кадра в области интерфейса); shimmer 0,1 на эффектном кадре. Свиши — никогда.
  Пик микса не выше пика голоса.
- Рендер: `REMOTION_BROWSER=<headless_shell> npx remotion render src/index.ts <Composition> out/<file>.mp4 --codec h264 --crf 16
  --audio-bitrate 320k --pixel-format yuv420p --concurrency=3 --timeout=120000` (черновик: CRF 20). Футаж 4K/60 сначала
  перекодировать в 4K/30 CRF 12 (`-g 30`) для скорости.

## Процесс нового дня
1. Скачать видео и озвучку из релиза в `public/news/<id>/` (большие файлы >100 МБ не коммитить, держать скрипт загрузки).
2. Карта футажа: раскадровка 1 fps, смены сцен (`select='gt(scene,0.01)'`), координаты ключевых строк — только на неподвижных кадрах.
3. Тайминги слов: sherpa-onnx GigaAM-v2 RNNT (модели из GitHub-релизов k2-fsa/sherpa-onnx), Whisper medium — для написания.
   Исправить написание (CS2, Fracture Case, числа цифрами), сохранить `data/news/<id>.words.json`. Текст не менять.
4. Планы по речи: заставка → 4–6 длинных планов на футаже. Спотлайт ровно на сказанном.
5. Звуки только на реальные события. Свишей нет.
6. Пробные кадры (`node scripts/stills.mjs`), правка кадрирования, затем рендер.
7. Проверка: первые 3 с, `blackdetect`, синхрон субтитров, финал, LUFS и пик (равны голосу).

## Запреты
Выдуманные цены, проценты, сделки, «графики»; изменение голоса; графика поверх футажа после заставки; свиши; замедленные кадры
в начале; спотлайт не на том, о чём говорится; эффекты, о которых автор не просил.
